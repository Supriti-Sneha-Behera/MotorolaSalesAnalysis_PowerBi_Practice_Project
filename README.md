# MotorolaSalesAnalysis PowerBi Practice Project

An interactive Power BI dashboard project built to summarize key sales
performance indicators for a Motorola sales dataset. The report is
designed to provide a quick view of sales performance and allow users to
explore results by month.

# Project Overview

This project uses Microsoft Power BI to present sales data in a compact
dashboard. It includes a month-based slicer and KPI cards for core
business metrics.

# Tools Used

* Microsoft Power BI 
* Microsoft Excel

# Objectives

-   Present important sales KPIs in one place.
-   Make monthly filtering straightforward.
-   Provide a simple, readable overview of sales performance.
-   Demonstrate the use of Power BI report visuals and interactive
    filtering.

# Repository Structure

1.  Download or clone this repository.
2.  Open MotorolaSales_PowerBI_File.pbix using Power BI Desktop.
3.  Wait for the report and model to load.
4.  Use the month slicer to change the reporting month.
5.  Review the KPI cards and compare the values under the selected
    filter context.
